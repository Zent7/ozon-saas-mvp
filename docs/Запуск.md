# Запуск проекта

## Что внутри
- `backend/` - API на FastAPI
- `frontend/` - интерфейс на React + TypeScript
- `docs/` - ТЗ, архитектура, схема БД, запуск
- `docker-compose.yml` - PostgreSQL для дальнейшего перехода с SQLite на Postgres

## Быстрый старт backend
Сейчас backend по умолчанию настроен на локальный SQLite-файл, чтобы можно было поднять MVP без отдельной БД.

### 1. Перейти в backend
```powershell
cd C:\Users\mihd0\Downloads\Вова\backend
```

### 2. Создать виртуальное окружение
```powershell
py -m venv .venv
```

### 3. Активировать окружение
```powershell
.venv\Scripts\Activate.ps1
```

### 4. Установить зависимости
```powershell
pip install -r requirements.txt
```

### 5. Запустить API
```powershell
uvicorn app.main:app --reload --port 8000
```

После первого запуска:
- автоматически создастся файл `medcenters.db`
- автоматически создадутся таблицы
- автоматически добавятся тестовые центры, услуги, шаблоны, клиенты и админ
