# План реализации и предварительная смета

## Общая оценка
Проект реалистичный, но по текущему описанию это уже полноценная рабочая система, а не простой справочник клиентов.

С учетом найденной действующей базы и необходимости миграции данных реалистичная оценка для одного сильного full-stack разработчика:
- MVP: 7-10 недель
- Полная первая рабочая версия с документами и миграцией: 9-12 недель

Если подключать второго разработчика или выделенного верстальщика/QA, срок можно сократить, но бюджет вырастет.

## Почему срок больше, чем кажется
Основное время уходит не на формы, а на:
- проектирование структуры данных
- перенос старой базы
- борьбу с дублями
- права доступа
- интеграцию шаблонов документов
- XML-выгрузки
- проверку сценариев сотрудников
- исправление нюансов после первых рабочих дней

## Этапы работ

### Этап 1. Аналитика и проектирование
Срок: 4-6 рабочих дней

Что делаем:
- анализ текущей базы Access и Excel
- фиксация состава сущностей и связей
- описание экранов
- утверждение MVP
- список шаблонов на первую очередь

Результат:
- согласованное ТЗ
- карта сущностей
- список шаблонов для первого релиза

### Этап 2. База, авторизация, центры, клиенты
Срок: 2-3 недели

Что делаем:
- проектирование БД
- авторизация
- роли пользователей
- поддержка двух центров
- список клиентов
- карточка клиента
- поиск
- защита от дублей

Результат:
- рабочая клиентская база в браузере

### Этап 3. Обращения, услуги, оплаты
Срок: 1.5-2.5 недели

Что делаем:
- создание обращения
- привязка услуг
- тип оплаты
- сумма
- комментарии
- история обращений клиента
- быстрый переход из поиска в обращение

Результат:
- закрывается основной ежедневный рабочий сценарий

### Этап 4. Документы и шаблоны
Срок: 2-3 недели

Что делаем:
- подключение шаблонов
- автоподстановка данных
- скачивание документов
- автонумерация бланков
- первичная XML-генерация

Результат:
- система начинает реально заменять текущую ручную работу

### Этап 5. Импорт, повторы, журнал, уведомления, бэкапы
Срок: 1.5-2.5 недели

Что делаем:
- миграция данных
- раздел повторных обращений
- журнал действий
- email-уведомления при удалении
- настройка резервного копирования
- тестирование на реальных сценариях

Результат:
- система готова к запуску в работу

## Предварительная смета

### Вариант 1. MVP
Состав:
- авторизация
- 2 центра
- клиенты
- обращения
- услуги
- поиск
- импорт базы
- журнал действий
- резервное копирование
- ограниченный набор шаблонов

Оценка:
- 180 000 - 230 000 руб.

Подходит, если:
- нужен быстрый запуск
- документы можно вводить поэтапно
- часть сложной логики переносится на второй этап

### Вариант 2. Полноценная первая версия
Состав:
- весь функционал MVP
- полный набор основных шаблонов
- XML
- повторы
- автонумерация
- email-уведомления
- детальная миграция и доработка после запуска

Оценка:
- 250 000 - 350 000 руб.

Подходит, если:
- нужно сразу заменить текущую систему
- документы и реестры критичны с первого дня
- нет желания запускать урезанную версию

## Что может увеличить срок и стоимость
- неструктурированные данные в старой базе
- большое количество реально используемых шаблонов
- сложные правила нумерации
- разные бизнес-правила по двум центрам
- нестандартный формат XML
- появление новых требований по ходу разработки

## Что поможет сократить срок
- выделить MVP и не перегружать первый релиз
- сначала подключить только самые нужные шаблоны
- заранее согласовать список обязательных полей
- зафиксировать правила дублей и автонумерации до начала разработки

## Рекомендуемый подход
Лучше идти в 2 релиза.

Релиз 1:
- база клиентов
- обращения
- услуги
- поиск
- два центра
- импорт
- основные шаблоны

Релиз 2:
- остальные шаблоны
- XML всех типов
- повторы
- дополнительные отчеты
- более гибкие права

## Рекомендуемый стек
- Frontend: React + TypeScript
- Backend: Python FastAPI или Node.js NestJS
- Database: PostgreSQL
- Документы: DOCX-шаблоны с автоподстановкой
- Аутентификация: session/JWT + роли
- Бэкапы: автоматические дампы PostgreSQL по расписанию
- Развертывание: VPS или локальный сервер клиента

## Вывод
Оценка "5-7 недель и 180-200 тыс." возможна только для сильно урезанной первой версии.

Если делать систему так, чтобы ей реально пользовались в двух центрах и она заменяла текущую базу и шаблоны документов, более честная оценка:
- по сроку: 7-10 недель на MVP, 9-12 недель на полную первую версию
- по бюджету: 180-230 тыс. за MVP или 250-350 тыс. за полноценную первую версию
