# Чистый архив для прогона

Цель: отдать другу или тестировщику архив без локального мусора, виртуальных окружений, `node_modules`, базы, видео и временных файлов.

## Что должно попасть в архив

- `backend/` с кодом, миграциями и `requirements.txt`;
- `frontend/` с исходниками Vite;
- `demo/` со статической демкой;
- `assets/templates/` с шаблонами документов;
- `docs/` с инструкциями и чеклистами;
- `docker-compose.yml`;
- `start-demo.ps1`;
- `backup-db.ps1`;
- `restore-db.ps1`;
- `DEMO_RUN.md`.

## Что не должно попасть в архив

- `.git/`;
- `.runtime/`;
- `.venv/` и `backend/.venv/`;
- `node_modules/`;
- `frontend/dist/`;
- `backups/`;
- `storage/`;
- локальные `.db`, `.sqlite`, `.log`;
- видео `*.mp4`, старые `*.rar`, временные `tmp_*`;
- локальный экспорт `demo/legacy-data.js`, если он содержит реальные клиентские данные.

## Как собрать

Из корня проекта:

```powershell
.\package-demo.ps1
```

Если для демонстрации нужен локальный экспорт старых клиентов `demo/legacy-data.js`, собрать так:

```powershell
.\package-demo.ps1 -IncludeLocalClientExport
```

Архив появится в папке `release/`.

| [ ] | Найти `node_modules` | Не найдено |
| [ ] | Найти `.runtime` | Не найдено |
| [ ] | Найти `*.mp4` и `*.rar` | Не найдено |

| [ ] | Проверить шаблоны | `assets/templates/` есть |

## Что отправлять вместе с архивом

Короткое сообщение:

```text
Распакуй архив в путь без кириллицы, например C:\medcenters-demo.
Открой PowerShell в папке проекта и запусти:
.\start-demo.ps1

После запуска открой:
http://localhost:5173/demo/index.html

Если что-то сломалось, заполни docs/bug-report-template.md и приложи скриншот.
```
