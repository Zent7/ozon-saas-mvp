# Места, где интерфейс пока не делает полноценное действие

Это список известных мест, которые во время субботнего показа надо либо подтвердить как нормальные временные заглушки, либо превратить в задачу.

## Найдено в демке

| Файл | Место | Что сейчас происходит | Что решить |
| --- | --- | --- | --- |
| `demo/app.js` | Экран разделов | Текст: "Этот экран пока оставлен как заглушка в демке" | Нужны ли отдельные полноценные экраны или оставляем основное рабочее место |
| `frontend/public/demo/app.js` | Экран разделов | Такая же заглушка в копии для Vite | Держать синхронно с `demo/app.js` |
| `demo/app.js` | Врачебные шаблоны | Для части ролей выводится "Шаблон пока не найден" | Сопоставить каждую роль с нужным DOCX |
| `frontend/public/demo/app.js` | Врачебные шаблоны | Такая же логика в копии для Vite | Держать синхронно |
| `demo/app.js` | Документы по услугам | Toast: "Для ... шаблон пока не добавлен" | После субботы заполнить карту услуга -> шаблон |
| `frontend/public/demo/app.js` | Документы по услугам | Такая же логика в копии для Vite | Держать синхронно |
| `demo/app.js` | Кнопки с `data-demo-toast` | Кнопки показывают сообщение, но не запускают действие | Решить, какие кнопки должны стать рабочими |
| `frontend/public/demo/app.js` | Кнопки с `data-demo-toast` | Такая же логика в копии для Vite | Держать синхронно |
| `demo/doctor-exam-modal.js` | Удаление осмотра | Alert: "Удаление осмотра потом добавим отдельно." | Нужна ли оператору/врачу возможность удаления |

## Что спросить в субботу

- Какие разделы реально нужны оператору каждый день, а какие можно скрыть.
- Какие кнопки должны выполнять действие сразу, а какие могут быть информационными.
- Кто имеет право удалять осмотры и обращения.
- Должно ли удаление быть физическим или только пометка "удалено".
- Какие сообщения об ошибках понятны сотрудникам, а какие надо переписать человеческим языком.

## Правило фикса

Если при прогоне нажали кнопку и "ничего не произошло", это баг только в одном из двух случаев:

- пользователь ожидал реальное действие;
- интерфейс не объяснил, что функция пока не подключена.

Если действие пока сознательно отложено, кнопку лучше скрыть или подписать так, чтобы не было ощущения поломки.
