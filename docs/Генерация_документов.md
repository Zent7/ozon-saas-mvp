# Генерация документов

## Что уже сделано
- реальные `DOCX` и `XML` шаблоны подключены в проект
- backend умеет загружать каталог шаблонов
- добавлен сервис генерации выходного файла
- поддержана подстановка по токенам и bookmarks

## Как это работает
1. Пользователь выбирает шаблон
2. Система получает данные клиента и обращения
3. Собирается контекст полей
4. Генератор создает новый файл в папке:

`C:\Users\mihd0\Downloads\Вова\storage\generated`

Этот каталог является runtime-хранилищем и должен входить в обязательный backup-контур вместе с PostgreSQL. Шаблоны из `assets/templates/` не заменяют backup рабочих документов.

## API

### Получить список шаблонов
`GET /api/v1/documents/templates`

### Сгенерировать документ
`POST /api/v1/documents/generate`

Пример тела запроса:

```json
{
  "template_id": 1,
  "client_id": 1,
  "encounter_id": 1
}
```

### Скачать сгенерированный файл
`GET /api/v1/documents/generated/{file_name}`
