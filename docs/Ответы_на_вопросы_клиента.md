# Ответы на частые вопросы клиента

## Это уже готовая система?
Нет, это интерактивная демонстрация логики и интерфейса будущей системы.
Она нужна, чтобы согласовать сценарии работы до начала полной разработки.

## Можно ли это быстро довести до рабочего продукта?
Да, на основе этой демонстрации и уже подготовленного технического каркаса можно переходить к боевой реализации.

## Что уже продумано?
- единая база клиентов
- работа двух центров
- обращения
- услуги
- документы и XML
- повторы
- роли и доступ
- антидубли
- автонумерация
- импорт текущей базы

## Что потребуется от клиента после согласования?
- список обязательных шаблонов
- правила XML
- правила автонумерации
- копия текущей базы и файлов
- список ролей и прав
- приоритеты для первой версии

## Что входит в первую рабочую версию?
Рекомендуемо включить:
- авторизацию
- клиентов
- обращения
- услуги
- поиск
- работу двух центров
- импорт базы
- основные шаблоны документов

## Что можно оставить на второй этап?
- расширенные отчеты
- все дополнительные шаблоны
- сложные интеграции
- расширенные уведомления
- дополнительные роли и правила
