# Импорт старой базы Access

Исходная база лежит здесь:

```text
storage/imports/2026-04-05 15_57 (2).mdb
```

Исходный `.mdb` импортёр открывает только на чтение. Сам файл не изменяется.

## Что импортируется

1. `tblMain` -> клиенты.
2. `tblServices` -> справочник услуг.
3. `tblVisits` -> обращения.
4. `tblOrderServices` -> услуги внутри обращений.
5. `tblCash` -> платежи/касса.

Для связи со старой базой в новых таблицах есть служебное поле `legacy_source_id`. Пользователь его не видит, но оно нужно, чтобы не потерять связь между клиентами, визитами и услугами.

## Предпросмотр

Из папки `backend`:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python .\scripts\import_legacy_mdb.py preview
```

Команда покажет количество записей и примеры строк. Данные в новую базу не записываются.

## Пробный прогон без записи

```powershell
python .\scripts\import_legacy_mdb.py run
```

Команда построит импорт, но в конце сделает откат. Это безопасная проверка.

## Реальная загрузка

```powershell
python .\scripts\import_legacy_mdb.py run --commit
```

После успешного импорта повторный запуск этого же `.mdb` не будет выполнен повторно, чтобы случайно не создать дубли.

## Требования

На Windows должен быть установлен Access Database Engine / Microsoft Access ODBC Driver. На текущем компьютере база уже открывалась через Access-драйвер, значит источник читается.
