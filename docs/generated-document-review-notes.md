## Что проверять в каждом DOCX/XML

| Статус | Проверка | Что смотреть |
| --- | --- | --- |
| [ ] | Открывается | Word/LibreOffice открывает файл без восстановления |
| [ ] | Внешний вид | Таблицы, переносы, подписи, печати, поля не съехали |
| [ ] | Данные клиента | ФИО, дата рождения, паспорт, адрес, телефон подставлены туда, куда надо |
| [ ] | Даты | Дата выдачи/осмотра/создания стоит в правильном формате |
| [ ] | Пустые поля | Нет видимых технических заглушек и лишних пустых строк |
| [ ] | Врачи | Врачебные поля и заключения попадают в нужные места |
| [ ] | XML | XML открывается как текст и содержит правильные теги/значения |

## Приоритет проверки

1. Водительские справки и XML.
2. ГИМС.
3. Медкнижка/ЛМК.
4. Справки 086у, 095у, бассейн, ГТО.
5. ЭКГ и УЗИ.
6. Договоры и медкарты.
7. Редкие шаблоны: гос.тайна, ЧОД, тракторная, 29Н, ГСУ.

## Что фиксировать как баг

- файл не открывается;
- Word предлагает восстановить документ;
- данные клиента подставились не туда;
- остались технические токены вида `{{...}}`;
- документ скачался, но пустой;
- выбран неправильный шаблон для услуги;
- XML сформировался, но не соответствует ожидаемому формату.
