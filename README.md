# Новый проект медцентров

В папке собран стартовый пакет по новому веб-проекту для двух медицинских центров.

## Документы
- `docs/ТЗ.md` - техническое задание
- `docs/План_и_смета.md` - этапы, сроки и предварительная смета
- `docs/Архитектура.md` - рекомендованный стек и архитектура
- `docs/Схема_БД.md` - предварительная схема базы данных
- `docs/Запуск.md` - как запускать текущий MVP-каркас
- `docs/Реестр_шаблонов.md` - подключенные шаблоны документов и XML
- `docs/Карта_полей_шаблонов.md` - привязка полей системы к шаблонам
- `docs/Генерация_документов.md` - как работает генерация документов

## Каркас проекта
- `backend/` - FastAPI backend
- `frontend/` - Vite-обёртка для сдачного демо-интерфейса
- `docker-compose.yml` - локальный PostgreSQL
- `frontend/public/demo/` - готовая демо-версия для показа клиенту
- `assets/templates/` - реальные шаблоны документов, распакованные из архива клиента

## Быстрый запуск
- Одна команда из корня проекта: `.\start.cmd`
- Альтернатива PowerShell: `.\start-demo.ps1`

## Основание для проектирования
- описание требований из переписки
- предварительный анализ текущей базы Access
- найденные сущности клиентов, обращений, услуг, пользователей и шаблонов
